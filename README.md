# Comparative Financial Performance Analysis of Canara Bank and Bank of Baroda in the Post-Merger Period (2020-2025)

MBA (Finance) Research Report

## Overview
This research report compares the financial performance of Canara Bank and Bank of Baroda over the five years after their mergers (2020-2025). It examines how profitability, asset quality, efficiency and financial strength changed after consolidation.

## Objectives
- Compare the post-merger financial performance of the two public sector banks.
- Analyse trends in key financial indicators over 2020-2025.
- Identify which bank performed better on each indicator.

## Methodology
- Period studied: 2020-2025
- Approach: ratio analysis using the banks' published financial statements
- Tools used: MS Excel
